What's in this one

Kept from The Signal

  • Two signals travel the map of offices on a 4.2s loop, offset by half so one is always moving — an introduction crossing town.
  • Eighteen nodes twinkle on staggered delays, so the network never looks static or synchronised.
  • The gold edge flows up and down the border on a 7s cycle.
  • A scrim holds the constellation behind the copy, so it reads as depth and never as clutter over the words.

Added from Living Archive

  • The ticking dial: a gold ring around the icon turning a full circle every 12s in 24 discrete steps — it ticks rather than glides, like a safe being worked.
  • A counter-turning dashed ring outside it on a slow 26s pass, so the two never line up twice.
  • The glow swells through the icon every 4.5s, and the rings still breathe outward.

The ⓘ fix — round two

  • The stutter is gone. The panel was opening on top of the ⓘ itself, which took the pointer off the icon — so it closed, which gave the pointer back, which opened it again, dozens of times a second. It now ignores the pointer entirely and opens below the header, so the icon stays hovered and the panel holds still.
  • It sits at the end of the card, after the button, so the paragraph and stats can no longer paint over it, and the panel is fully opaque (#0A0B12).
  • No fade. A panel that cross-fades over body copy shows both layers at once and reads as broken every time — this one snaps in fully formed, or isn't there at all.
  • Still pure CSS — no scripting, so it works in a preview, on the live site, and on keyboard focus.

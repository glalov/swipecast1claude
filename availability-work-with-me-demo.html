Decisions baked in (flag anything you want changed)

  • No email, phone or links anywhere. Every button goes through CastSlate messaging/invites, so your no-contact-info rule still holds and CDs can't bypass the platform.
  • Buttons are viewer-adaptive, same logic as Manager Mode Concept 3: CDs get Request self-tape / Invite; other actors only see Message; logged-out visitors get the free-account funnel (return-to-profile preserved).
  • Status never lies. A "Booked until" date that passes should auto-flip back to Available (or the pill hides) instead of showing a stale date.
  • Free vs Premium: status + "open to" free; next-available date, response time, and an auto "recently active" signal as Premium extras.
  • Not built yet: needs a profile column (e.g. availability jsonb), the editor card, and the strip component in TalentProfile. Realistically about one session once you approve.

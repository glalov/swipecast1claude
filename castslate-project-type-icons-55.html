CastSlate · browse card · Gel Chip

All 55 project types, three palettes

Every entry in PROJECT_TYPE_OPTIONS now has its own solid Gel Chip glyph — fifty-five marks, no repeats, no fallbacks. The three demos below are the same fifty-five icons at three levels of colour, so the only thing you are judging is how loud you want the browse page to be.

One icon per type, not per family. This drops the nine-family grouping from the last round — every type in the dropdown is drawn individually, so “Off-Off-Broadway Theater” is a literal black box, “Table Read” is a table with three people and a script on it, and “Motion Capture” is a tracking-dot skeleton. The groups below still exist, but now they only drive colour in the first two palettes — never which glyph you get.

Demo A

Full Spectrum

Each of the eleven groups owns a hue, so the tile colour carries information before you read a word — film indigo, theatre plum, on-set rust, development green. Strongest at a glance on a mixed browse page; the most colour CastSlate has ever carried in one view.

11 tints · 11 inks · colour = group
